# BioCatalyst Intelligence 2.4 · 反应条件检索版

## 本次改动

在原有 BioCatalyst Intelligence 2.3 基础上，新增左侧独立入口 **「按反应条件查」**，以及四大研究方向页内「按反应条件查 → 温压/流量/能耗表」。原有四方向文献浏览、原料溯源、催化剂表、三表关联、个人笔记、CSV 导入导出、Obsidian MD 导出及 GitHub Actions 每日文献元数据更新继续保留。

### 反应条件表默认字段

1. 反应类型 / 反应编号（关联催化剂名称、研究方向、证据状态）
2. 反应器类型（石英管 DBD、固定床、间歇釜等，保留原文）
3. 催化剂用量（g，按原文记录）
4. 原料及气体流速（各自独立列值，显示时整合；cm³/min）
5. 反应温度（℃，支持“约 100 ± 5”等原文表述）
6. 反应压力（保留“常压”、MPa、bar 等原文描述）
7. 功率 / 能量输入（记录原始功率/电位/光强等及原文单位）
8. 反应模式（连续、间歇、逆流、流化等）
9. 原料及来源、关联催化剂、证据/来源

筛选：关键词、驱动方式、反应器类型、温度区间、压力类型、功率或能量类型、连续/间歇模式。可以导出“当前筛选结果” CSV，点击实验/催化剂进入详情与原文核验字段，进入「三表联动」继续查询催化剂性质与产品组成。

### Ir/GaN 示例（来自用户提供截图，待全文核验）

- 反应器：DBD 石英管反应器（同轴不锈钢电极）
- 催化剂：0.1 wt% Ir/GaN；用量 0.1 g
- 原料：生物质热解油，0.05 cm³/min；CH₄，100 cm³/min
- 温度：约 100 ± 5 ℃；压力：常压
- 放电功率：12 W；反应模式：连续逆流（气液逆流、催化剂流化）

此条仅依据上传截图，不代表已核对论文完整实验方法。原料原始生物质来源尚未从截图确认，产品值缺失时不填补。**放电功率 W 不等于实际总能耗 kWh，不能与其他技术的能效直接比较。**

## 使用

- **本地版**：下载单文件 HTML，双击浏览器打开。浏览、筛选、添加反应条件及导出 CSV 可离线运行。更换设备/浏览器请先备份 JSON。
- **在线更新版**：将整个项目目录（包括隐藏的 `.github`）上传到自己的 GitHub 仓库，启用 Settings → Pages 和 Actions → 每日文献更新 → Run workflow。项目任务配置按北京时间每日 08:17 执行，平台可能延迟；首次真实抓取需要用户部署后验证。
- **功能边界**：计划任务每天更新 **论文题录与可获得的摘要**，不会自动填充论文的反应条件/催化剂用量/能量输入或全文定量性能。后者需要论文全文与表图核验后手动加入矩阵。
- **既有数据**：建议升级前在旧版本点击备份，保留自己的阅读记录、催化剂证据及实验数据。
